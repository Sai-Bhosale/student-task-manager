# 🎓 Student Task Manager

A simple and user-friendly web application that helps students organize college assignments, track deadlines, and manage their academic tasks.

## 🚀 Live Demo

[Open Student Task Manager](https://student-task-manager-31qm.onrender.com)

## ✨ Features

- **Dashboard:** View total, pending, in-progress, and completed tasks.
- **Add Tasks:** Create tasks with titles, descriptions, status, and due dates.
- **Task Management:** Mark tasks as completed or delete them.
- **Database Integration:** Store and retrieve tasks using PostgreSQL.
- **REST API:** Perform CRUD operations through an Express.js backend.
- **Responsive Design:** Simple interface for managing tasks.

## ⚙️ Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Sai-Bhosale/student-task-manager.git
   ```

2. Open the project folder:

   ```bash
   cd student-task-manager
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file and configure your PostgreSQL database credentials.

5. Start the application:

   ```bash
   node server.js
   ```

6. Open `http://localhost:5000` in your browser.
